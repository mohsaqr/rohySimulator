Fast paths to a first success, plus a teaching walkthrough and the media production standards. Every page here is a condensed happy path — it points into the full guides for anything beyond the shortest route.

Training only

The simulated patient is not real and the simulator does not provide medical advice. Nothing in these tutorials is clinical guidance.

Quickstart vs. full guide

A quickstart is the shortest sequence of steps that gets you one working result — log in and finish a case, stand up a class, bring the app up locally. It deliberately skips options, edge cases and "why".

A full guide (under Using the Simulator, Teaching with Rohy and Running Rohy in Production) covers the same ground with every option, fallback and constraint. Each numbered step in a quickstart links to the guide page that explains it in full — read the quickstart to move, read the guide to understand.
